### ⚠️ 若遇到bug，请换最新Edge浏览器。
- **chrome**：下载第二个文件点不动，且在桌面端加解密速度缓慢。
- **手机自带浏览器**：最新往往也不支持生成/验证Ed25519密钥
- **Via**：下载文件的优化不太行。
- **Edge**: 有时候可能不能正常预览媒体。

**R7-7840HS配Edge143，GCM加解密1.97GiB文件用时均不到9秒。**

**骁龙6Gen1，Via和Edge差不多速度，若文件200MB以内，加解密速度约44MB/s。**
